* stores a varied instruction set, however instructions and the data are living in the exact same memory block, they have to share the exact same physical wire (the bus) to get to the CPU.
* has 3 essential components:
  1.  Central processing unit:
      1. Arithmetic logic unit
      2. Control Unit : fetches and decodes instructions and sends signal to ALU on what to do
      3. General purpose Registers
  2. single storage memory unit 
  3. Memory mapped I/O devices
