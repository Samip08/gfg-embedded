Header files: #include <stdio.h> contain standard input/output functions like printf, scanf

How a C file runs:
1. write a code.c file and compile it using a compiler GCC, Clang, MSVC
2. compiler converts into an executable file and loads into memory
3. cpu executes the main program in the code file
Used in:
* os- developing os like linux, UNIX due to efficiency and hardware level access
* systems- used for device drivers, assemblers, linkers and system utils
