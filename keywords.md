[[control flow keywords]]


* storage class keywords: auto, register, static, extern
* define the lifetime, scope and visibility of variable. where is it stored, for how long, how to access it

* auto storage: stack , initial val: garbage,  scope: within block, life: end of block
* extern storage: data segment, initial val: zero, scope: global/multiple files, life: end of program
* static storage: data segment, initial val: zero, scope: within block, life: end of program
* register storage: cpu reg, initial val: garbage, scope: within block, life: end of block

* auto is just a normal local variable
